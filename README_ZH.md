## 功能

- **📱 设备仪表盘** —— 型号、iOS、存储、**电量、循环次数与健康度**、序列号、UDID、芯片、Wi-Fi，USB 或 Wi-Fi 实时读取。
- **✨ 自定义** —— 核心功能：yuri 自动识别设备是**原版、TrollStore 还是已越狱**，并**只解锁可用的工具**。普通设备上的越狱工具会明确标注锁定原因。
- **📦 应用** —— 查看用户与系统应用、卸载，并通过 USB **安装已签名的 IPA**，带进度条。
- **🗂️ 文件** —— 浏览媒体分区（照片、下载、录音）并导出文件。
- **📜 实时日志** —— 带筛选的实时系统日志。
- `EN · RU · 中文`，浅色与深色。

全部在本地 `127.0.0.1` 服务器运行，每次启动使用新令牌。设备不会连接任何云端。

## 安装

**Linux**
```sh
git clone https://github.com/murk-sus/yuri4iPhone && cd yuri4iPhone
./install-linux.sh
yuri4iphone
```

**Windows / macOS** —— 从 [Releases](https://github.com/murk-sus/yuri4iPhone/releases) 下载。Windows 需安装 iTunes 或 Apple 设备驱动。
